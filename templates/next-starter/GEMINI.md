# GEMINI.md

Lee y cumple `AGENTS.md` antes de modificar el proyecto.

Antes de iniciar o continuar una tarea, lee `bitacora.md`. Al finalizar cada avance relevante, agrega una entrada con fecha/hora, cambio y validación usando:

```bash
npm run bitacora -- "descripción del avance"
```

No borres ni reescribas entradas anteriores.
