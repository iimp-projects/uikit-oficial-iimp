# Reglas obligatorias del kit

Las aplican los componentes y, donde se puede, ESLint con `--max-warnings=0`. Cada mensaje de error dice qué componente usar.

## Tablas

Las cabeceras (`TableHead`) ya traen la tipografía oficial: Manrope 600, 13px, MAYÚSCULAS, tracking amplio y color muted. No las sobrescribas con `text-*` ni `font-*`.

## Logo del sidebar

`DashboardSidebarBrand` muestra el logo a 35px de alto y ancho automático. Para otra marca autorizada: `logoSrc` y `logoAlt`; para ajustar el `img`: `logoClassName`. No uses `!important` ni CSS global.

## Botones

- **Solo icono:** `size="icon"` (`icon-sm` o `icon-lg`) + `aria-label`; si el significado no es obvio, envuélvelo en `Tooltip`. Con espacio, icono + texto. Regla `iimp/icon-button-label`.
- **Dos o más botones seguidos del mismo nivel:** dentro de `ButtonGroup`. Excepciones: footers de dialog o card y combinaciones Primary + otra variante. Regla `iimp/prefer-button-group`.
- **Pares de color:** todo `bg-secondary` o `bg-primary` lleva su `text-*-foreground`.

```tsx
<ButtonGroup>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button size="icon" variant="outline" aria-label="Ver detalle"><EyeIcon /></Button>
    </TooltipTrigger>
    <TooltipContent>Ver detalle</TooltipContent>
  </Tooltip>
  <Button size="icon" variant="outline" aria-label="Editar"><PencilIcon /></Button>
</ButtonGroup>
```

## Formularios

- Varios campos en una fila: `FormGrid`. Calcula las columnas según el ancho real del contenedor (1 en un drawer, varias en una página) y llena cada fila sin huecos. `minFieldWidth` (por defecto 14rem) fija el ancho mínimo cómodo; `className="col-span-full"` da fila propia a un campo.
- Prohibido: `grid-cols-N` o `flex` en fila con varios `FormField`, anchos fraccionarios (`w-1/4`, `w-[25%]`, `basis-*`) en el campo o su contenedor, y anchos fijos en el control (`w-40`, `w-fit`, `max-w-*`). Regla `iimp/form-grid`.
- Los controles, incluido el `Select`, llenan su celda y quedan alineados por fila.
- **Descripciones:** van en la prop `description` de `FormField`. Se muestran en un icono de ayuda (`?`) junto a la etiqueta: hover para verla, clic para fijarla, Escape para cerrar; sigue disponible para lectores de pantalla. Un `p` muted o un `FieldDescription` suelto junto al campo lo marca `iimp/field-description`.

```tsx
<FormGrid>
  <FormField label="RUC" required><Input /></FormField>
  <FormField label="Código" description="Opcional. Único."><Input /></FormField>
  <FormField label="Notas" className="col-span-full"><Textarea /></FormField>
</FormGrid>
```

## Filtros

Buscador, selects y botón van en `FilterBar`: una fila que se envuelve según el ancho. Nada de un control por fila ni estirado al 100 %. Regla `iimp/filter-layout`.

## Cero errores

TypeScript estricto (`strictTypeChecked`, sin `any`, promesas esperadas), `eslint . --max-warnings=0`, y `prebuild` = typecheck + lint + seguridad.
